# Cortex Cloud Engineer

Version 0.1.0. Canonical source: this directory. Begin with [SKILL.md](SKILL.md); read the domain references only when the task calls for them. The agent adapter is host-specific metadata, not a separate executing agent.

Provide the objective, exact product/management surface, sanitized evidence and action scope. The Skill can design, review and troubleshoot without a live tenant; unknown schema and permissions remain explicit.

Runtime packages contain SKILL.md, VERSION, agents, references, templates and examples. Tests, validation records and scoring criteria stay outside the runtime. Sibling Skills are optional.

See [validation](VALIDATION.md), [cases](tests/cases.md) and [changelog](CHANGELOG.md). Installation/import and target-product execution require their own evidence; publication does not perform them.
