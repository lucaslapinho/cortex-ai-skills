## Updated decision rules

- Expiration, deletion, exclusion, export and enforcement are distinct lifecycle events. New data may reactivate an expired indicator; confirm downstream behavior instead of assuming expiry revokes every control.
- DBotScore categories represent verdicts (0 unknown, 1 good, 2 suspicious, 3 bad); they are not percentages or independent authorization to block a subject.
- Export Indicators Service remains deprecated; use the documented Generic Export Indicators Service where the product/deployment supports it. Verify installed pack version, long-running service/engine path, effective query and actual exported content.
- Query parameters can influence export selection. Treat authenticated access and filtering as separate boundaries; test intended scope and avoid assuming a default query is an access-control policy.
- The current Generic Export documentation marks Cache Lock Timeout/Age deprecated and describes fail-fast concurrency behavior. Do not prescribe those old tuning parameters as active controls; inspect the installed version and current cache/concurrency settings.
- Firewall EDL consumption requires separate evidence: service output, retrieval/authentication/format, refresh/expiry, policy reference and actual enforcement. Publishing an indicator alone is not a block. Integrate with the firewall specialist using the exact manager/device scope and recovery plan.
