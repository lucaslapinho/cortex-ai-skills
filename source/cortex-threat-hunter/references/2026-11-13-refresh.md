## Updated decision rules

- Graph Search requires the documented entitlement and Graph Search-specific RBAC. An empty graph may reflect missing coverage, filters or scope; it does not prove absence of risk.
- Each graph/table result represents a matching path. The guide bounds displayed paths at 50 and its runtime detail view at the last 100 events; those displays are not an exhaustive event corpus. Record view limits and obtain bounded source evidence before quantitative conclusions.
- Distinguish graph reachability/posture from observed runtime activity and demonstrated exploitation. The runtime layer is itself dependent on collected data. Use source timestamps and entity alignment before correlating a cloud identity, asset and process.
- Case grouping helps collect related issues but does not prove one actor or attack chain. Investigate benign alternatives and independent evidence.
- For a cloud hunt, establish provider scope, inventory/audit/scan/runtime coverage and entitlement. For a firewall hunt, establish traffic forwarding, actual inspected path, logging, retention and known-positive events. Hand off coverage gaps before claiming a negative result.
